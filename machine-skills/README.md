# Machine skills (การใช้เครื่องจักร)

เก็บขั้นตอนการใช้เครื่อง (3D printer, CNC, laser cutter ฯลฯ), ไฟล์ G-code และค่าตั้งเครื่อง

สำหรับแต่ละเครื่องให้ระบุ: รุ่นเครื่อง/ซอฟต์แวร์, การเตรียมเครื่อง, ไฟล์ input, ผลที่คาดหวัง, และข้อควรระวังด้านความปลอดภัย
⚠️ ตรวจสอบคำสั่งทุกครั้งก่อนรันบนเครื่องจริง
