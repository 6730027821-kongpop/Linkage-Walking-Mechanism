# Simulation (การจำลอง)

## `Symbolic_Math_verFinally.m` — Linkage Walking Mechanism (ขาเดียว)

วิเคราะห์จลนศาสตร์ (kinematics) ของกลไกเดินแบบ linkage ขาเดียวด้วย Symbolic Math

🎥 **วิดีโอสาธิต:** [YouTube Shorts](https://youtube.com/shorts/H6VvG0fA-Pw)

### ทำไมทำเป็นขาเดียว
โปรเจกต์นี้เลือกวิเคราะห์และสร้างกลไกเพียง **ขาเดียว** เนื่องจาก **ข้อจำกัดในการประกอบ Hardware**
การจำลองและผลลัพธ์ทั้งหมดในไฟล์นี้จึงเป็นของขาเดียว (single leg)

**ส่วนประกอบของกลไก**
- ก้านหมุน (crank) รัศมี `r` หมุนรอบจุด O = (0, 0) ด้วยมุม `th`
- ปลอก (collar) Y ยึดกับตัวถังที่ (0, `d`)
- ก้านแดงยาว `L` ต่อจากหมุด P ลอดผ่านปลอก Y ไปที่ปลายบน T
- ขาตั้งตรงเสมอ (เลื่อนผ่านตัวเลื่อนในร่องแนวนอน) เท้า F = T − [0; `H`]

**ขั้นตอนในสคริปต์**
| Step | เนื้อหา |
|---|---|
| 0 | วิเคราะห์ DOF ด้วย Grübler equation |
| 1–3 | ตัวแปรสัญลักษณ์, ตำแหน่งหมุด/ปลอก, สมการเงื่อนไขของก้านแดง |
| 4 | ตำแหน่งเท้า F(θ) และตรวจ DOF จาก Jacobian |
| 5 | ความเร็วและความเร่งของเท้า |
| 6–7 | แทนค่าตัวเลข และคำนวณ stride, step height, duty factor, ความเร็ว/ความเร่งสูงสุด |
| 8 | กราฟ trajectory และ kinematics (บันทึกเป็น PNG) |
| 9 | ภาพเคลื่อนไหวของกลไก |

**พารามิเตอร์ที่ใช้ (หน่วย mm, rad/s)**
| `r` | `d` | `L` | `H` | ω |
|---|---|---|---|---|
| 22.465 | 50.00 | 165.22 | 273.582 | 2π (60 rpm) |
