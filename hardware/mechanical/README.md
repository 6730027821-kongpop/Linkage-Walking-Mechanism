# Mechanical hardware (ชิ้นส่วนกลไก)

เก็บไฟล์ CAD ต้นฉบับ (เช่น .SLDPRT, .f3d, .step), แบบ drawing (PDF) และไฟล์สำหรับผลิต (.stl, .dxf)

- ระบุโปรแกรม CAD และเวอร์ชันที่ใช้: [เช่น SolidWorks 2024 / Fusion 360]
- ใส่เลข revision ในชื่อไฟล์ เช่น `bracket_rev03.step`
- บันทึกวัสดุ, ค่าความคลาดเคลื่อน (tolerance) และวิธีผลิต
